Component Catalog

Katatsukuri UI

長期保守するWebアプリケーションで生じるUIの重複と実装差を、サーバー主導の責務を保ったまま減らすための、 framework-agnosticなWeb Components UIライブラリです。特に業務システムや既存MPAへの段階導入を想定しています。 各項目を開くと、その場で実際のexampleを操作できます。

はじめに 全体アーキテクチャ コンポーネント設計 テーマ設計 GitHub
